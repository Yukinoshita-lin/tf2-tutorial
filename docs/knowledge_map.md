# 知识地图：你在哪，要去哪，为什么这么走

> 这张地图回答三个问题：**我要去哪？我现在在哪？这条路为什么这么走？**
> 建议把它打印出来贴在桌边，每学完一章回来打个勾。
> 图例：`──►` 主线路径；`- - ►` 可选支线；`[ ]` 过关标准（跳一跳够得着）。

---

## 1. 主线故事：一条线贯穿全书

所有章节都在做**同一件事**——把"看图识花"从一个想法做成能跑在树莓派上的真系统：

```
 我想让电脑看图识花
        │
        ▼
 [第0章]  电脑怎么"学"？——不是写规则，是喂例子        （建立直觉）
        │
        ▼
 [第1章]  学习的数学底座：张量 + 梯度下降              （拆开黑盒）
        │
        ▼
 [第2章]  用 Keras 把黑盒装回去：三行代码训练          （工具上手）
        │
        ▼
 [第3-5章] 三种数据形态：图片 / 图片 / 文本            （举一反三）
        │      MLP → CNN → 词向量
        ▼
 [第6章]  数据不够怎么办？站在巨人肩上（迁移学习）     （突破瓶颈）
        │
        ▼
 [第7-8章] 从"能跑"到"能管"：监控训练 + 导出模型       （工程化）
        │
        ▼
 [09实战]  独立完成一个完整项目（从数据到报告）        （综合验收）
        │
        ▼
 [10实战]  把模型塞进树莓派：量化 + 现场推理           （走向真实世界）
        │
        ▼
 目标达成：你独立做出了一个"看得见摸得着"的 AI 系统
```

**为什么这条主线这么走？** 每一步都在解决上一步暴露的真实瓶颈：

| 卡点 | 解决它的章节 | 为什么放在这个位置 |
| --- | --- | --- |
| "机器学习"三个字很玄 | 00 | 不破除玄学，后面全是死记硬背 |
| 三行 Keras 是魔法，不知道里面干了啥 | 01 | 先拆开黑盒再看 API，才不会"会用但不懂" |
| 手写 NumPy 太累 | 02 | 体会过痛点，才知道 Keras 帮你省了什么 |
| 全连接网络对图片效率低 | 04 | 学过 MLP 才能理解 CNN 为什么要"卷" |
| 图片会做了，文本呢？ | 05 | 换一种数据，检验你是否真的懂了流程 |
| 自己的数据只有几百张 | 06 | 数据不够是现实约束，迁移学习是标准答案 |
| 训练过程像黑箱，崩了都不知道 | 07 | 模型变复杂之前，先装好仪表盘 |
| 训练完模型锁在内存里 | 08 | 不能保存部署的训练等于没发生 |
| 以上都学了但没连起来 | 09 | 知识点不经过完整项目就会忘 |
| 模型只在 GPU 服务器上能用 | 10 | 真实世界的大多数设备没有 GPU |

**可以怎么跳**：

- **有 Python + NumPy 基础**：可略读 00/01，从 02 直接开始，但请做 01 的过关自测确认。
- **只想尽快出结果**：00 → 02 → 06（直接用迁移学习），一两天内做出一个能用的分类器，再回头补 03-05。
- **目标偏工程/部署**：主线走 00-02 → 07 → 08 → 10，视觉章只精读 06。
- **手册进阶章 9/10/11**（读论文、调参、调试）不属于代码主线，遇到对应问题时随时插入。

## 4. 理论线 × 工程线：双轨并行

全书刻意"理论与工程并重"。同一章里，两条线的比重不同：

```
            理论浓度 ▲
   01 张量/求导  ████████████
   10 手册·调参  ██████████
   11 手册·调试  █████████
   00 基础概念   ████████
   03/04/05     ██████
   06 迁移学习   █████
   02 Keras     ████
   07 回调监控   ███
   08 保存导出   ██
   09/10 实战    ██
                        工程浓度 ►
```

- **理论线的落点**：每章"🧠 直觉理解"＋"🔍 为什么这样设计"；深入题在手册 10/11 章。
- **工程线的落点**：每章"✋ 动手试一试"＋可运行脚本；集成训练在 09/10 实战。
- 两条线在**每个阶段末尾的过关标准**汇合：光懂原理做不出、光会调参讲不清，都算没过关。

## 6. 学习周期可无限拉长：主线之后的三级台阶

主线（14 天）走完后，地图并不封顶——学习周期按需无限拉长：

```
 [主线毕业]
     │
     ├─ 第一级 · 进阶篇（2-4 周）
     │    进阶篇 11-15: 数据管道 / RNN / 注意力 / 生成模型 / 自定义训练
     │    （每一章都是"可运行 + 可实验 + 可报告"的完整单元）
     │
     ├─ 第二级 · 学期制（16 周）
     │    docs/study_plan_semester.md:
     │    5 个两周专题(各配实验报告) + 调参调试 + 4 周大项目 + 自评分表
     │
     └─ 第三级 · 终身路线（不设期限）
          想更深理解原理？ ──► 手册10 调参 · 11 调试
                             ──► Chollet《Deep Learning with Python》
                             ──► Goodfellow《Deep Learning》(数学向)
          想换模型家族？ ──► Transformer 深入(进阶13 之后) · ViT
                           ──► Jay Alammar《The Illustrated Transformer》
          想做更难的任务？ ──► 目标检测 · 图像分割 · 扩散模型(进阶14 之后)
          想走工程深处？ ──► tf.data 性能调优(进阶11 之后) · 分布式 · TFX
                           ──► 用 10 章的树莓派做点真东西

**节奏建议**：主线 14 天（见 `study_plan.md`）→ 进阶篇 2-4 周 →
学期制 16 周（见 `study_plan_semester.md`）→ 终身不设期限。
每周固定 2 小时走三个月，胜过收藏夹里囤一百篇教程。
