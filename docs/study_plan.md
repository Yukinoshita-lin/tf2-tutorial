## 前言：这个计划给谁看？

这个计划是为**零基础但有一定 Python 基础的计算机专业学生**设计的。如果你：

- 会写 Python，知道 NumPy 是什么，但从没接触过深度学习
- 想学 TensorFlow/Keras，但面对海量资料不知道从哪下手
- 想在两周内对深度学习有一个"能动手、能理解"的完整认识

那么这个计划就是为你准备的。

### 每天学多久？

- **标准节奏**：每天 1-2 小时
- **第 11-13 天（综合项目）**：可能需要 2-3 小时，建议安排在周末
- 如果某天时间不够，可以把当天内容拆成两天，不用硬撑

### 怎么用这份计划？

1. **打印出来**，每天完成后在对应位置打勾，有仪式感更容易坚持
2. **先读章节再动手**，代码一定要亲手敲一遍，光看是学不会的
3. **过关自测要诚实**，答不出来就回去再看一遍，不要骗自己
4. **卡住了很正常**，翻到末尾的"卡住了怎么办"看看建议

- [ ] 分类头（Classification Head）：加在预训练模型后面的几层

## 如果某一天卡住了怎么办

学习路上卡住是**完全正常**的，谁都经历过。遇到困难时，试试下面几个方法：

### 1. 先停 10 分钟，换个脑子

卡壳的时候硬扛，效率极低。站起来走一走、喝点水、看看窗外，让大脑后台悄悄处理一下。很多时候，问题的答案会在你不刻意想的时候突然冒出来。

### 2. 把报错信息完整读一遍

90% 的报错信息里已经告诉你问题在哪了。不要一看到红色字就慌，认真读：
- 错误类型是什么？（`ValueError`？`ShapeMismatch`？）
- 错误描述说了什么？
- 报错的是哪一行代码？

如果是 shape 不匹配，把每一层的 shape 都打印出来，一个一个核对，总能找到问题。

### 3. 回去看对应的章节和练习题答案

很多时候你遇到的问题，练习题里已经讲过了。翻回 `teaching/exercises.md`，找到对应章节的代码改错题，看看是不是踩了同样的坑。

### 4. 善用搜索，但别直接复制粘贴

遇到问题去搜索是好习惯，但**一定要理解答案为什么对**，而不是复制粘贴完能跑就行。不然下次遇到类似的问题你还是不会。

### 5. 找同学讨论，或者给"橡皮鸭"讲一遍

把问题讲给别人听（甚至讲给一个橡皮鸭听）的过程中，你经常自己就想明白了。这叫"橡皮鸭调试法"——解释问题 = 理清思路。
